## 🚀 About Me

I'm a software engineer who builds backend systems and cloud applications, focused on **LLM inference systems**: the engineering that makes large language models fast, reliable, and affordable to serve.

* ⚡ **Inference:** prefill vs. decode, KV cache, continuous batching, quantization, speculative decoding, vLLM
* 💻 **Software engineering:** REST APIs, backend services, and full-stack apps in Java, Python, Node.js, and C#
* ☁️ **Cloud:** AWS (Lambda, Bedrock, S3, RDS, EC2) · AWS Certified Cloud Practitioner · Google Cloud Digital Leader
* 🎓 MS in Information Systems (Trine University) · BE in Computer Science (Osmania University)
* 🎯 **Goal:** build AI infrastructure that serves LLMs at scale with low latency and high throughput

---

## 🔭 Currently Working On

* ⚙️ Building a single-server LLM inference engine from the ground up: prefill/decode, KV cache, batching, quantization
* 🚀 A speculative decoding project to speed up token generation
* 📦 Scaling inference: orchestration on Kubernetes plus latency and throughput monitoring
